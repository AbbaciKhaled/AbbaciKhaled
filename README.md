## Development Philosophy

1. **Clarity over cleverness** — code is read far more often than it is written; optimize for the reader
2. **Architecture before implementation** — the decisions made first compound over the entire project lifetime
3. **Performance by default** — budget response times and bundle size before writing a single line, not after
4. **Composition over configuration** — small, focused modules that combine predictably beat large, flexible abstractions
5. **Ship, then iterate** — real usage surfaces requirements that no specification anticipates
6. **AI as leverage, not automation** — integrate models where they reduce cognitive load, not where they obscure logic
7. **Own the full stack** — understanding each layer makes the whole system more reliable, not just the parts you authored
